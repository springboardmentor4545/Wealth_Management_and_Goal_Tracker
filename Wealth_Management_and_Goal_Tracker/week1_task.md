# Week 1 — Tasks

Overview
- Goal: Set up your environment, learn core language basics, and complete a small exercise.
- Deliverable: Push your work to GitHub and open a PR with the branch `week-1`.

Setup (do these first)
- Install required tools: Git, Python 3.10+ (or project-specified), and a code editor (VS Code recommended).
- Create a project folder and initialize git: `git init`.
- Create and activate a virtual environment: `python -m venv venv` then activate it.
- Install any starter requirements if provided.

Core Exercises
- Exercise 1: Hello & I/O — write a script that asks for your name and prints a greeting.
- Exercise 2: Variables & Types — create examples using strings, integers, floats, lists, and dicts.
- Exercise 3: Control Flow — write functions that use `if/else` and loops to process a list.
- Exercise 4: Functions — implement small reusable functions and include docstrings.

Mini Project (required)
- Build a simple CLI calculator that supports add, subtract, multiply, divide:
  - Provide a help message and accept user input.
  - Include basic validation and error handling (e.g., divide by zero).
  - Write 3 short unit tests for core calculator functions.

Submission
- Create a branch named `week-1`.
- Commit your work with clear messages and push to your remote repository.
- Open a Pull Request and include a short description of what you implemented and any known issues.

Acceptance Criteria
- Code runs without syntax errors.
- Core exercises completed and visible in repo.
- Mini project implemented and includes at least 3 tests.
- PR created with the `week-1` branch.

Optional Stretch
- Add a README section describing how to run your code and tests.
- Add basic input parsing to allow command-line arguments.
